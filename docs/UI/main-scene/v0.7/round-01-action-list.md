- 负责人：任俊茹
- 原则：先完成 P1，再处理 P2；不在本清单中新增未确认剧情或系统

## 目标

把 v0.6 已确认的玩法和叙事逻辑转化为可验证的界面状态、操作路径和系统反馈，使玩家能够：

1. 理解自己位于美丽理发店并处于自由探索状态；
2. 发现并选择吴莉或价目表；
3. 完成价目表查看、回忆／对话与返回场景；
4. 理解自己的行为形成了新认知；
5. 在后续 D104 中获得由价目表线索解锁的新对话行为。

# 玩家认知链验收

```text
价目表线索
↓
发现可交互高亮
↓
查看并阅读内心记录
↓
理解价格、街坊关系与吴莉经营处境
↓
形成新认知
↓
解锁 D104 新对话行为
↓
获得进一步信息
```

验收条件：

- [ ] 玩家能发现价目表，而不依赖旁白重复描述画面。
- [ ] 玩家能理解为什么要查看价目表。
- [ ] 查看后存在可感知但不过度写实的内心认知反馈。
- [ ] 认知状态能持久保存到 D104。
- [ ] D104 正确读取状态并解锁对应对话选项。
- [ ] 未完成前置交互时，D104 不错误解锁选项。
