## 1. 设计目标

把 v0.6 已确认的玩法与叙事逻辑转化为可验证的状态线框，确保玩家能发现价目表、完成查看与阅读、形成新认知，并在后续 D104 对话中获得由线索解锁的新行为。

## 2. 界面架构与状态归属

本页采用跨界面流程方案：六个主要界面是一级系统，十个 Frame 是玩家操作流程中的状态快照。

| 一级界面 | 核心目的 | 本轮对应状态 |
|---|---|---|
| 主场景界面 | 根据现有美术出图，探索生活 | 01、02、03、04、07 |
| 对话界面 | 引导剧情推进，建立人物关系 | 08 |
| 轻量互动节点 | 对话后提供主动调节与叙事呼吸 | 09、10 |
| 物品界面 | 探寻触发，发现身份线索 | 05、06 |
| 梦境界面 | 故事插曲，连接过去 | 由 06 的“回忆”进入；正式梦境 Frame 后续设计 |
| 人物档案 | 重新理解他人 | 接收线索影响；本轮未设计独立 Frame |
| 记忆地图 | 整理真相 | 接收线索节点；本轮未设计独立 Frame |

## 3. 状态线框

1. `01_MainScene_Enter`：从地图进入美丽理发店。
2. `02_MainScene_Exploration`：自由观察并选择吴莉或价目表。
3. `03_Object_PriceList_Available`：价目表高亮并显示互动 Icon。
4. `04_Object_PriceList_Selected`：聚焦价目表，一级操作为“查看”。
5. `05_Object_PriceList_Inspection`：进入笔记本式物件信息页。
6. `06_Object_PriceList_AfterRead`：阅读后出现“回忆／对话”操作；“回忆”进入梦境界面。
7. `07_MainScene_Exploration_AfterClue`：返回场景并保留已查看／已理解状态。
8. `08_D104_Option_Unlocked`：D104 读取价目表线索并解锁新对话选项。
9. `09_Smoking_Relaxation_QTE`：温柔／理智线在对话收束后触发一次轻量 timing QTE；失败无惩罚。
10. `10_Smoking_FirstPerson_Street`：点烟成功后的第一人称永安街街景，展示 3–5 秒并允许跳过。

## 4. 核心交互链

| 状态 | Trigger | Player Action | System Response | New State | Next Available Action |
|---|---|---|---|---|---|
| Enter | 从地图进入理发店 | 按 `Space` 进入 | 显示地点与场景标题 | Exploration | 选择人物或物件 |
| Exploration | 场景加载完成 | 移动焦点 | 可交互对象高亮 | Object Available | 聚焦价目表 |
| Object Available | 指向／接近价目表 | 确认对象 | Icon 与对象名称出现 | Object Selected | 查看或取消 |
| Object Selected | 价目表被选中 | 按 `E` 查看 | 打开物件信息页 | Object Inspection | 继续阅读 |
| Object Inspection | 信息页打开 | 按 `Space` 阅读 | 展示吴莉的内心记录 | After Read | 回忆、对话或返回 |
| After Read／回忆 | 阅读完成 | 选择“回忆” | 关闭物品界面并进入故事插曲 | 梦境界面 | 经历过去片段并返回 |
| After Read／对话 | 阅读完成 | 选择“对话” | 进入人物对话 | 对话界面 | 获取或验证人物信息 |
| After Read／返回 | 阅读完成 | 返回主场景 | 保存已查看／已理解状态 | Exploration After Clue | 继续探索 |
| Exploration After Clue | 返回主场景 | 继续探索 | 价目表显示已查看 | Clue Persisted | 进入后续 D104 |
| D104 Unlocked | 进入 D104 且线索满足 | 选择新选项并完成对话 | 收束到 `D104_k_merge` | Route Check | 判断是否进入点烟节点 |
| Route Check | 对话收束 | 系统检查路线变量 | 温柔／理智线进入 QTE；暴力／激进线跳过 | Smoking QTE / Observation | 点烟或直接观察 |
| Smoking QTE | `$d104_entered_gently` 或 `$d104_apology_cleared` 为真 | 指针进入 18%–22% 目标区时按 `Space`／点击 | 成功进入第一人称街景；失败无惩罚 | First-person Street / Observation | 等待、跳过或开始观察 |
| First-person Street | 点烟成功 | 观看 3–5 秒，或按任意键／点击 `SKIP` | 播放环境氛围与克制独白 | Observation | 点击物件进行观察 |

## 5. 交互与 HUD 规则

- 十个状态以用户确认的 v0.6 原图为母版；09、10 作为对话后的轻量过渡节点，只增加必要状态差异。
- `Exploration`：右侧对话面板隐藏；显示对象提示；`E` 仅在对象选中后出现；`ESC` 返回上一层或取消聚焦。
- `Dialogue`：只有进入人物对话时才显示右侧对话面板；仅显示对话选项与对话控制。
- `Smoking QTE`：只在温柔／理智路线的对话收束后出现一次；目标区占整条 20%（允许在 18%–22% 内微调），成功与失败均不要求重试。
- `First-person Street`：仅作为成功后的叙事奖励，持续 3–5 秒；右上角常驻 `SKIP`，按任意键也可结束。
- 09、10 隐藏常规场景 HUD、Scene Feedback 与 Notebook Bar，避免与 QTE／主观视角争夺注意力；仅保留烟条和跳过入口。
- 右下角笔记本及人物档案、记忆地图、设置入口在当前草稿中按“主场景常驻功能栏”处理，最终显示时机待用户确认。
- `Object Inspection`：在主场景母版上打开物品信息层；保留唯一一级确认操作；`ESC` 返回主场景。
- 已查看状态返回场景后保留；重复查看不重复触发错误状态。
- 价目表属于物件交互系统，不并入 Dialogue 系统。

## 6. 视觉与组件布局

- 主场景背景使用用户提供的正式美术图，按 `1920 × 1080` 中心裁切；场景中的人物、镜台、门窗和价目表均属于背景美术，不再额外搭建重复场景组件。
- 价目表热点绑定在画面右侧墙面现有价目表上，仅叠加可互动、选中和已查看状态，不移动或重画价目表。
- 时间与操作提示采用左上角紧凑 HUD，避开中央人物、镜台及右侧价目表。
- 地点标签位于左下角；笔记本功能栏位于右下角，避免遮挡主要角色和门口区域。
- 自由探索不显示右侧对话面板；进入人物对话时，面板从右侧覆盖出现，此时允许遮挡部分场景信息。
- `08_D104_Option_Unlocked` 以场景参考图中的人物站位、空间关系和视线关系重新构图左侧场景 viewport：两名角色同时处于主要视野，站立角色位于左前景、坐姿角色位于中右区域，人物关系成为左侧视觉中心。
- 08 已按相同视觉外观拆分重搭：`Scene Viewport` 独立裁切场景，HUD、Scene Feedback、Dialogue Panel 与 Notebook Bar 均为场景上方的独立可编辑图层，不再由场景图覆盖。
- Camera Framing 仅调整 `Scene Viewport` 内部的裁切、缩放与取景位置；不得覆盖标题、时间、操作提示、地点、对话面板或笔记本。
- 01–07 已按 [00_Global_Rules](v0.7/global-rules.md) 的 Layer Order 完成分层整理。
- 物品界面使用居中浮层，背景保留主场景关系但降低操作优先级。
- 黄色用于可交互／主要操作，青色用于当前聚焦，绿色用于已查看／已理解。
- “新认知”反馈位于画面下方中央，保持轻量、内心化，不采用写实证物风格。
- 07 的 Scene Feedback 使用 `X610 / Y816 / W700 / H72`，以完整画布中心对齐；与右下角 Global Navigation 保持至少 `32px` 净空。
- 08 与 07 使用同一套 `1920 × 1080` 连续场景空间，底图铺满完整画布；对话面板、HUD 与导航均叠加在底图上方，未被 UI 覆盖的区域不得出现空白。08 仅调整底图内部的 Camera Framing，使人物关系保持当前视觉中心。
- 07 与 08 的 Scene Feedback 尺寸统一为 `W700 / H72`。07 位于 `X610 / Y816`；08 沿用上一版左侧场景视觉中心，位于 `X274 / Y816`，避免与右侧 Dialogue Panel 贴靠。

### 6.2 09–10 点烟放松节点

```text
08_D104_Option_Unlocked
  ↓ 对话收束 D104_k_merge
Route Check
  ├─ 温柔／理智线 → 09_Smoking_Relaxation_QTE
  │                    ├─ 成功 → 10_Smoking_FirstPerson_Street
  │                    │          └─ 3–5 秒／SKIP → Observation
  │                    └─ 失败 → Observation（无惩罚）
  └─ 暴力／激进线 → Observation（跳过 09、10）
```

- 09 使用单次 timing QTE：轨道 `1080 × 36px`，目标区默认 `216 × 36px`（20%），指针从左向右匀速移动。
- 09 失败不显示负向评价、不扣数值、不要求重新尝试，只失去额外街景与独白。
- 10 采用冯涵第一人称街景，底部烟条为 `1320 × 56px`，右上角 `SKIP` 为 `160 × 48px`。
- 10 当前街景为结构线框，占位表达街道透视、店铺关系、手部与香烟位置；正式美术需后续替换。
- 09 的 `QTE_Background_Viewport` 与 10 的 `First_Person_Street_Viewport` 均固定为 `1920 × 1080` 全屏接口，按 `scene_id + time_state + weather` 加载静态图或动画。
- `Environment_Background / Environment_Animation` 只承载环境资源；QTE、烟条、独白和 SKIP 始终作为独立上层 UI，不嵌入背景资源。
- 10 的手部、香烟和烟雾放入独立 `FirstPerson_Foreground`，更换清晨／白天／黄昏／夜晚风景时无需重新调整 UI。

建议脚本接口：

```text
ShowFirstPersonStreet(
  scene_id="barbershop_exit",
  time_state=current_time,
  weather=current_weather,
  duration=4,
  can_skip=true
)

返回：completed / skipped
```

## 9. 本版变化

- 保留 v0.6 历史版本，并将用户提供的正式主场景美术确立为 v0.7 状态母版。
- 重做并扩展为 10 个状态线框：保留原 01–08，并新增点烟 QTE 与第一人称街景。
- 新增 `00_Global_Rules`，锁定安全区、8px 网格、字号、间距、圆角、描边、组件尺寸和 Layer Order。
- 将 01–07 按全局 Layer Order 重构为可编辑分层 Frame。
- 将 08 从合成图拆分为独立 Scene Viewport、Persistent HUD、Scene Feedback、Dialogue Panel 与 Global Navigation，修复场景覆盖顶部 HUD 的问题。
- 将价目表识别为场景美术中的现有物件，交互反馈直接绑定其画面位置，不再生成独立价目表组件。
- 自由探索状态隐藏右侧对话面板，仅在人物对话状态显示。
- 明确 06“回忆”进入梦境界面，并保留“对话／返回”分流。
- 补齐对象状态、主要操作和反馈链。
- 将仍需产品决策的笔记本显示时机、系统边界与触发条件明确标记为待确认。
