# 主场景 UI 设计说明

- 页面名称：主场景
- 英文名称：Main Scene
- 当前版本：v0.6
- 文档状态：设计中
- 更新时间：2026-09-10

## 1. 设计目标

建立主场景页面的基础信息架构，为后续视觉设计和交互评审提供统一文档。

## 2. 页面结构

1. 顶部状态栏
2. 玩家信息区域
3. 主场景展示区域
4. 任务或活动入口
5. 底部功能导航栏
6. 设置及辅助入口

## 3. 功能与交互

| 区域 | 功能 | 交互说明 |
|---|---|---|
| 顶部状态栏 | 展示资源和状态 | 具体资源类型与点击行为待确认 |
| 玩家信息 | 展示头像、昵称和等级 | 点击后的目标页面待确认 |
| 主场景 | 展示核心场景和角色 | 可交互物件范围待确认 |
| 任务入口 | 展示当前任务 | 入口样式和优先级待确认 |
| 底部导航 | 进入主要功能页面 | 导航数量和顺序待确认 |

## 4. 视觉与适配要求

- 保持核心信息层级清晰
- 主要操作按钮使用统一视觉规范
- 图标风格和尺寸保持一致
- 文本与背景保持足够对比度
- 适配目标设备的安全区域
