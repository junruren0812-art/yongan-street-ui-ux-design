## 3. 核心规格

| 字段 | 规格 |
|---|---:|
| Resolution | `1920 × 1080 px` |
| Aspect Ratio | `16:9` |
| Safe Area | `48 px` |
| Grid | `8 px` |
| Narrative Panel | `528 × 696 px`，`X 1344 / Y 144` |
| Avatar Group | `208 × 96 px` |
| Location | `320 × 48 px` |
| Notebook Group | `280 × 120 px` |

## 4. 已接受的设计决策

1. 主场景保持全屏，以保留环境叙事。
2. Dialogue 以 overlay 形式覆盖场景，不替换或裁切场景区域。
3. 叙事控制与探索控制视觉分离。
4. 时间与叙事控制位于左上区域。
5. Notebook 与探索控制组合在右下区域。

## 5. 控制映射

| 类型 | 按键 | 操作 |
|---|---|---|
| 叙事 | `Space` | 继续 |
| 叙事 | `ESC` | 返回 |
| 探索 | `E` | 互动 |
| 探索 | `Tab` | 笔记本 |
